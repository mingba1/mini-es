# 03 · BM25 与 Lucene 风格 IDF

BM25 是关键词路默认打分。mini-es 使用 **Lucene 变体**（与 ES 默认 `BM25Similarity` 一致的 IDF 形式），参数：

- \(k_1 = 1.2\)
- \(b = 0.6\)
- 默认字段 boost：`title=3`，`content=1`

## 公式

对集合/段文档数 \(N\)、含词文档数 \(n=\mathit{df}\)：

\[
\mathrm{idf}(t) = \ln\!\Bigl(1 + \frac{N - n + 0.5}{n + 0.5}\Bigr)
\]

词频归一（长度惩罚）：

\[
\mathrm{tfNorm}(tf, L) = \frac{tf\cdot(k_1+1)}{tf + k_1\bigl(1 - b + b\cdot L/\mathit{avgdl}\bigr)}
\]

单项贡献：

\[
\mathrm{score}(t,d) = \mathrm{idf}(t)\cdot \mathrm{tfNorm}(tf(t,d), L(d))
\]

查询项最终：

\[
\mathrm{contrib} = \mathrm{score}(t,d)\cdot \mathrm{fieldBoost}(f)\cdot \mathrm{queryBoost}
\]

多 term / 多字段在 `BooleanQuery` 中 **相加**。

> 经典 Robertson–Sparck Jones IDF 写作 \(\ln\frac{N-n+0.5}{n+0.5}\)；Lucene 在外层加 `1+` 再 `ln`，避免负 IDF，并与历史实现兼容。

## 伪代码

```
function idf(n, N):
  return ln(1 + (N - n + 0.5) / (n + 0.5))

function bm25(tf, docLen, avgdl, idf, k1=1.2, b=0.6):
  if tf <= 0 or avgdl <= 0: return 0
  norm ← 1 - b + b * (docLen / avgdl)
  tfNorm ← tf * (k1 + 1) / (tf + k1 * norm)
  return idf * tfNorm

# TermQuery:
idf ← idf(df, segment.numDocs)
avgdl ← segment.avgFieldLength(field)
for each posting:
  scores[docId] += bm25(posting.freq, fieldLen, avgdl, idf)
                  * fieldBoost * queryBoost
```

## 复杂度

| 操作 | 时间 |
|------|------|
| 预计算 `idf` | \(O(1)\) / term |
| 打分一条 posting 链 | \(O(\mathit{df})\) |
| 多 term 查询 | \(O(\sum \mathit{df}_i)\)（未做跳跃优化时） |

\(k_1\) 控制 TF 饱和速度；\(b\) 越大，越惩罚长文档。`b=0.6` 比 Lucene 历史默认 `0.75` 略弱长度惩罚，适合标题短、正文长的文档。

## mini-es 落点

- `BM25Similarity.DEFAULT_K1 = 1.2f`，`DEFAULT_B = 0.6f`
- `TermQuery` 按段计算 `idf` / `avgdl`，再乘 `segment.fieldBoost(field)`
- `MultiMatchQuery` 对 title/content 展开 SHOULD，title 侧常带 boost 3

## 「真实 ES / Lucene」对照

| mini-es | Lucene / ES |
|---------|-------------|
| `BM25Similarity` | `org.apache.lucene.search.similarities.BM25Similarity` |
| 段级 \(N, \mathit{avgdl}\) | 通常按 **segment** 统计；ES 亦可 index 级 similarity 设置 |
| `k1=1.2, b=0.6` | ES：`index.similarity.*.k1/b`；Lucene 默认多为 `k1=1.2, b=0.75` |
| `fieldBoost × queryBoost` | `IndexableFieldType` boost（旧）/ query-time boost；ES `multi_match` 字段 `^3` |
| 无 `norm` 字节压缩 | Lucene 可把长度归一编码进 norms |

ES mapping 示例：

```json
"similarity": {
  "biz_bm25": { "type": "BM25", "k1": 1.2, "b": 0.6 }
}
```
